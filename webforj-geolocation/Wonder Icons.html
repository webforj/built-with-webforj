The Engraver's Plates

Every wonder rendered as a single-subject line device, drawn from the same hand so they read as plates from one book. Each sits in a 3:2 sepia plate frame ready to receive a true engraving.

❖❖❖❖

How to use & export these

These are stylized line devices, not photographic engravings — coherent, legible at any size, and free of slop. To export:

  • As code — every device lives in js/emblems.js as window.EMBLEMS[key]. Colour comes from three CSS hooks: .ink, .faint, .ink-stroke.
  • As files — standalone, self-contained SVGs (styles inlined) are written to /svg/<key>.svg — drop straight into the webforJ project.
  • Swapping in real plates — the 3:2 frame is the contract. Place a public-domain engraving (Wikimedia Commons / NYPL / British Library) into the plate and the device steps aside. Match it to the frame: monochrome, sepia-toned, single centered subject.
